# ᴄᴀʟʏᴘꜱᴏʙᴏᴛ

A professional Telegram group management bot with AI chat, moderation, fun commands and more.

## Deploy on Render

1. Fork/push this repo to GitHub
2. Go to [render.com](https://render.com) → New → Web Service
3. Connect your GitHub repo
4. Set environment variables (see below)
5. Deploy — done

## Environment Variables

| Variable | Required | Description |
|---|---|---|
| `BOT_TOKEN` | ✅ | Get from [@BotFather](https://t.me/BotFather) |
| `GROQ_API_KEY` | ✅ | Get free from [console.groq.com](https://console.groq.com) |
| `LOG_CHANNEL` | ❌ | Channel ID for action logs |
| `STORAGE_CHANNEL` | ❌ | Channel ID for stats persistence |

## Features

- Moderation — ban, kick, mute, warn, tban, tmute
- Welcome/Goodbye messages with placeholders
- Anti-flood, anti-spam, anti-link, anti-forward
- Filters, notes, blacklist, locks
- Captcha for new members
- Join request approval system
- AI chat (Groq — Hinglish, human-like)
- AI image generation
- Leaderboard/ranking with chart image
- Quote sticker generator
- Fun commands — kiss, slap, hug, ship, roast, 8ball, roll, flip
- Utility — calc, weather, translate, wiki, define, remind, poll
- Broadcast to all groups + PM users
